EXCEL SOURCE FILES
==================
Place your Gartner Excel analysis file here.

Default filename the converter looks for:
  Gartner_Contract_Renewal_Analysis.xlsx

Or pass any filename explicitly:
  python scripts/excel_to_json.py excel/your_filename.xlsx

IMPORTANT: .xlsx files are excluded from git (see .gitignore).
Only the generated JSON in public/data/ gets committed.
